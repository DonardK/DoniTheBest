# Lumen

Windows installer and setup guide.

The installer is about 221 MB, so it is attached to [Releases](https://github.com/DonardK/DoniTheBest/releases) instead of stored in this file list. GitHub rejects files larger than 100 MB.

1. Open **Releases** and download `Lumen-0.1.0-setup.exe`.
2. Follow [guide.md](guide.md) to install Lumen and add your own TMDB, Prowlarr, and OpenSubtitles keys.
